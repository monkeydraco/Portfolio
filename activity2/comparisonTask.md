1. Which extension changed your day-to-day typing/editing experience the most?
   Prettier changed the day-to-day editing experience the most because it automatically formats code by fixing indentation, spacing, and quote styles. It makes code cleaner and easier to read without manually formatting it.

2. Which extension is about the code itself (correctness/formatting) vs. about collaboration/history?
   Python and Java extensions mainly help with writing, running, debugging, and understanding code. Prettier focuses on code formatting. On the other hand, GitLens focuses on code history, such as who changed a line and previous commits, while Live Share focuses on real-time collaboration.

3. Which extension would you keep enabled for every project, and which only for specific languages?
   I would keep Prettier and GitLens enabled for most projects because formatting and version-history features are useful across many projects. I would use the Python extension specifically for Python projects and the Java Extension Pack specifically for Java projects.

4. How did Live Share change the feeling of pair programming compared to screen sharing?
   Live Share makes pair programming more interactive than ordinary screen sharing because both people can work on the same file simultaneously and see each other's cursor, selections, and edits in real time. It can also allow sharing a terminal, making collaboration feel more like working together on the same computer.
